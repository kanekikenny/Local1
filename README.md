# Local1：本地大模型科学推理项目

课程项目：3000题题库、本地模型调用与判分、监督输出头训练、对照实验、错误分析、图表和汇报PPT。

## 下载与恢复完整项目

网页上传版本采用分包保存，完整源码、数据、训练输出头和实际实验记录都在分包内。先下载本仓库 ZIP 并解压，或克隆仓库。在此目录执行：

```bash
python3 restore_project.py
```

脚本依次合并六个分包、核验SHA-256，并解压为 `local_science_project/`。项目入口和依赖说明见解压目录的 `README.md`。约1.36GB基础模型不随仓库提供，通过项目内 `setup_local.py` 首次下载并校验，之后可离线推断。

## 已完成的实际实验

- 精确3000题：2900道ARC原题，另保留100道历史数值题。
- 训练2000题、验证300题、最终测试600题。训练和测试保持隔离。
- 本地Qwen3-1.7B Q4_K_M，模型主体冻结，训练8196参数的新增输出头及校准控制，未执行主体SFT或LoRA。
- 4700次正式冻结模型前向，22项自动检查通过，部署入口已实际运行。

| 方法 | 600题正确率 |
|---|---:|
| 本地原模型 | 76.00% |
| 温度校准 | 76.00% |
| 偏置校准 | 75.83% |
| 监督输出头 | 75.83% |
| 随机双示例 | 77.00% |
| 检索双示例 | 75.17% |

预先指定的配对比较均未显示显著提升。输出头改善了本测试集的置信度校准指标，但没有提高总体准确率。完整负面结果与改错案例均保留。新选择题成绩不能与历史大学数值题成绩直接比较。
